# 第3回 — マルチャミーによる代替可能性

2026年11月27日。増殖するG（G）、フワロス（F）、プルリア（P）、ニャルス（N）のドロー対象、初手保有率、固定展開でのドロー機会、手札増減を比較。5,832条件の厳密計算、6種類の構築方針×100万初手状態の抽選。9ルートに同じ初手を再利用。勝率や実戦の展開選択は測定していません。

[記事全文・出典](article.md)

## 実行方法

Python 3.11以上。検証環境 NumPy 2.3.5、Matplotlib 3.10.8。日本語グラフ生成には Noto Sans CJK JP を推奨（非同梱）。

```sh
cd maxx-c/03-mulcharmy
python -m pip install -r requirements.txt
python simulate.py --trials 1000000
```

動作確認は `--trials 10000`。乱数シード2026112703。出力は同じフォルダ内のCSV・PNGを上書きするため、公開結果を残す場合は別フォルダへコピーして実行してください。

## ファイル

- `routes.csv`：第2回からの6ルート、M∀LICEの2部分ルート、仮想長展開。`board` は終盤の相手フィールド枚数の仮定。
- `deck_profiles.csv`：実在の公式WCS構築3件。2025年2枚・2026年1枚の増G採用を反映。
- `opening_overlap.csv`：初手保有率と重複率。
- `route_draws.csv`：単独発動・無効なしの召喚元別ドローと純増。対応回数0でも発動したと仮定した純増は−1。
- `results.csv`：全5,832条件。`coverage` は1枚以上ドロー、`positive_net` は手札5枚超、`gross` は平均ドロー枚数、`net_before`/`net_after` は手札調整前後の初手からの純増（無効でも発動コストを引く）。確率は0〜1表記。
- `monte_carlo.csv`：54条件での厳密値と乱数照合。6種の初手抽選を9ルートに再利用する。対策札状態は各ルートで独立抽選。
- `candidate_draws.csv`：残り35枚中の候補5/8枚という固定条件の追加取得確率。
- `run_log.txt`：実行結果。PNG3点は基本の積極戦略を表示。

## 条件の読み方

`usage_k3_N0` は採用者が各マルチャミー3枚採用、ニャルス採用率を仮に0%とした条件。k=1/2/3、N=0/20/50（%）を比較。採用率は11月5日スナップショットの独立仮定。実在3構築と合わせ計12構築条件。

`keep` は維持、`ban_other` はG枠をその他へ、`ban_F` / `ban_P` / `ban_N` はそれぞれのカードへ可能な範囲で置換、`ban_FPN` はF→P→Nの順で3枚上限まで置換。40枚を保つ。大会の共有カード規定や置換後の採用率の変化は再現しない。

`single` はドロー枚数最大の1効果、`stack` は対象召喚があるGと最大2枚のマルチャミーを発動、`net_optimal` は期待純手札増加を最大化する発動数（発動しない選択も可能）。全て召喚前に発動、固定ルートを知る理想化。`none` は無効なし、`ash` は相手初手うらら保有率約32%で最多ドローの効果1つを無効、`always_one` は必ず1つ無効。他カードの無効・手札消費・追加誘発による展開中断・途中発動は再現しない。最適化は実際のプレイヤー判断を示すものではない。
